## 四、编写口径与硬约束（可机器核验）

以下 13 条在《工具\跨文档核验.py》与人工复核中逐条检查。

1. **六层名称与顺序**逐字照抄《02》§8.1：用户交互层 → 业务服务层 → 智能问答层 → 向量检索模块 ‖ 图谱检索模块 → 数据知识层，不得改名、不得增删层。
2. **六个功能模块名称**逐字照抄《02》§6.2：财经信息管理、财经事件抽取、事件知识图谱、智能问答、证据追溯、历史问答。
3. **本体口径**照抄《02》§9.2：6 类实体（Company／Person／Industry／Institution／Event／Policy）、8 种核心事件类型、9 条核心关系、事件六项核心属性。
4. **证据属性**一律写"**除 EVIDENCED_BY 外**，其余 8 条核心语义关系统一携带 source_doc_id、source_chunk_id 与 confidence"；EVIDENCED_BY 的证据是其指向的 Document 节点。**不得出现"每条关系都带证据属性"的无限定表述**。
5. **FAISS** 一律表述为"向量索引"或"向量检索组件"，**不得称"向量数据库"**。
6. **MySQL 恒为六张表**，不得新增表；**user 表始终建立**（第一版不启用登录业务，该表保持为空、不写入数据），不得写成"可选表／可以不建立"；session_id 是 question 表的字段；history 表已删除、不得复活。
7. **data_cutoff_time 是数据集版本级属性**，不属于任何表；"最新／最近（30 天）／近期（90 天）"一律按 event_time 判定。
8. **0 跳与未启用图谱扩展时**，图谱路径区域显示"本次回答未使用图谱扩展"，**不得生成虚构路径**。
9. **不引入《02》§8.4 的技术**（LangChain／LlamaIndex、独立向量数据库、Elasticsearch、Kafka、微服务、K8s、Agent、多模态与语音、实时行情）；技术栈固定为 Vue 3 ＋ FastAPI ＋ MySQL ＋ Neo4j ＋ FAISS ＋ 大模型 API ＋ Docker。
10. **具体模型名称与版本保持 TBD**（Embedding 模型与大语言模型的选型在第 12.4 节实验配置固定表中"选型后固化"），本阶段不得写死型号。
11. **接口范围限于第一版**：不做注册、不做找回密码、不做多角色与细粒度权限；登录仅在条件满足时以最小"仅登录"形态出现。
12. **来源可回溯**：每一节的设计条目必须能指向《07》的 FR／UC／NFR 编号或《02》的具体节号；找不到来源的设计不得写入。
13. **实验配置的对应关系必须照抄《02》**：**Method ＝ 消融 C 组**（Vector RAG + 2-hop KG，不启用时间过滤与证据排序），**Baseline 2 ＝ A 组**（《02》§12.5、§12.6）；**Top-K 证据集合的五步契约照抄《02》§12.7**，尤其"两路候选按 chunk_id 去重、同一文本块只算一个证据"与"保留到 K 个这一步先于 D／E 分组排序"两条不得改写——这两条是实验可复现与 E 组单变量的前提。

## 六、本阶段明确不做的事（非目标）

1. **不写实现代码**：不写类的方法体、不写函数实现、不写前端组件代码、不写 Cypher 查询语句（除本体 schema 的必要示意）。
2. **不做界面设计**：不出版面稿、配色方案与高保真原型；只可以给"页面元素清单"。
3. **不做部署运维细节**：不写 K8s、CI/CD、监控告警、备份恢复方案；Docker 只说到"统一运行环境"这一层。
4. **不做安全专项**：不写渗透测试、鉴权体系细化，除 NFR-06 已冻结的三项（密钥不入前端、输入长度与频率限制、口令摘要存储）。
5. **不进入第 5、6 阶段的领域**：不做数据采集与清洗口径、不写抽取规则与提示词内容、不做标注方案。
6. **不选模型**：不写 Embedding 模型与大语言模型的具体型号、版本与调用参数。
7. **不改实验方案**：《02》§12 的测试集、消融、指标定义已冻结，本阶段只引用、不重新论证。
8. **不做 UML 全套图**：只做支撑第四章论证所需的最小图集，不做类图全家桶。
