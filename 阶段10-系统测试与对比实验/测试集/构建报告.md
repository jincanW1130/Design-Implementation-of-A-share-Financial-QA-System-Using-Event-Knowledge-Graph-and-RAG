## 缺陷 1（必改）：`time_window` 字段形态两批不一致

**改前**

* 批 A（48 道时间约束题）：`{"label": ..., "start": "2026-08-26", "end": "2026-09-25"}`
* 批 B 与 30 题预实验集：`{"lo", "hi", "label", "basis", "cutoff", "empty_policy"}`

**改后**

两批与终稿统一采用**预实验集的六字段形态**、键序固定：

```json
{"lo": "2026-06-27", "hi": "2026-09-25", "label": "近期90天",
 "basis": "event_time", "cutoff": "2026-09-25T23:59:59+08:00", "empty_policy": "exclude"}
```

* 批 A 的 48 道逐题换算 `start→lo`、`end→hi`，并补齐 `basis`／`cutoff`／`empty_policy`；
* `cutoff` 取 `data_cutoff_time` 的规范时间戳形式（预实验集同值）；
  `empty_policy` 取 `exclude`（预实验集同值，与《02》第 12.7 节"空值一并剔除"一致）；
* `basis` 恒为 `event_time`。

**落点**：`建正式测试集_A.py` 的 `W()`／`WE()` 与 `build_records()`、`建正式测试集_B.py` 的
`make_window()`、`合并正式测试集.py` 的合并期断言。

**实测证据**

```text

  [批A] 时间约束题 48 道；过滤前后差集验证通过 48 道
  [批A] 自检通过（0 错误，0 警告）        → 退出码 0
批 B：python "阶段10-系统测试与对比实验\工具\建正式测试集_B.py" --idempotent
  [确定性] 二次生成逐字节一致 = True
  [校验] 错误 0 条；警告 0 条 -> 退出码 0
决策者核验：

```

66 道时间约束题的 `time_window` 键集合只有**一种**（PE 集口径），批 A 的 `{start,end,label}` 形态已消失。
