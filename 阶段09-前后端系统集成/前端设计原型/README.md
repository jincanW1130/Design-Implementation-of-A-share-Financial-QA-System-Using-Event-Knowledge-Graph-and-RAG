## 一、作者第二轮四条意见（2026-09-30）与实现

| 作者原话 | 实现 |
| --- | --- |
| 「知识图谱可视化做的不够好应该**更详细更准确**」 | 7 类节点（Company／Person／Institution／Event／Policy／Industry／Document）各一种形状＋颜色＋**可读图例**；节点显示名称＋代码、按**连接数分级大小**；**有向箭头**（`marker-end`）＋**中文关系名**（任职／参与／发布／属于／相关／客户关系／同业竞争／证据指向）＋边的四项属性（`role`／`confidence`／`source_doc_id`／`source_chunk_id`，**置信度用线宽编码**）；点击/悬停出**属性面板**（空值显示 `—（空）`）；**类型复选筛选／深度 1↔2 切换／时间区间过滤／缩放平移重置／Tab＋Enter 键盘可达**；**点边可「跳到对应证据」**（按 `source_chunk_id` 定位高亮）；**路径列表与画布联动**；**孤立节点单列**并写明「未出现邻接边」；常驻**准确性声明**「数据来源：本次返回的 **17 条路径 / 10 节点 / 6 边**」「**图谱深度上限 2 跳**」 |
| 「点击证据直接能跳转到相关财经新闻或者报告（**来源**）」 | 每条证据卡与历史回看证据表都加：**来源站名 ＋ 域名**（如 `巨潮资讯网 · static.cninfo.com.cn`）＋「**查看原文 ↗**」外链（`target="_blank" rel="noopener"`）。8 条证据的 `url` **逐字取自真实接口** `GET /api/evidence/16` 的原样返回；其中证据 1／3 是同文档两个块（URL 相同、`chunk_id` 1337001／1337000），2／4 同理——**照实分列不合并** |
| 「回看历史时也要**知识图谱可视化**」 | 回看抽屉由「三张表」扩为四段：问题 → 答案四段 → 证据表（含外链与「定位证据」）→ **图谱路径可视化**（复用屏③同一套渲染器、图例与声明），并显式标注口径：**「按当时记录的路径载荷还原 · 不重新查询图谱」**——数据来自 `answer.graph_path` 的原始 JSON 文本，看到的是当时的真实结果，不是图谱当前状态 |
| 「**实时数据再完善一些**，比如当时重大新闻、相关股近一周的重要报告」 | 实时区扩成**三块**：① 实时行情（价格/涨跌幅/成交额/`更新于`）② **当时重大新闻**（时间·标题·来源·外链）③ **相关股近一周的重要报告**（日期·标题·类型·PDF 外链）。**统一两态**（默认「未接入」／可切「已接入（实测形态）」），并给出**不依赖外部源的降级形态**——**语料内近一周**（2026-09-18~09-25，库内 **58 篇**：巨潮 46／证券日报网 5／中国政府网 4／中证网 3，常驻可用）。实时区标题旁常驻声明：**只作展示、不进入问答证据链；答案锚定语料截止 2026-09-25** |

## 三、已知限制（如实登记）

1. **未做真实浏览器渲染验证**：本机无浏览器自动化，OpenDesign 的截图导出只在桌面运行时可用
   （`screenshot export is only available in the desktop runtime`）。生成方以 headless 量测 `scrollWidth ≤ 视口`（1440 宽无横向滚动）＋ 静态断言替代；我另做 77 项文件级核验。**界面外观本身仍未经人眼确认——请在浏览器里看一次**。
2. **原型不是 `代码\前端\` 的 Vue 实现**：设计→组件移植仍属延后项。**注意两者已有差距**：原型的图谱、外链、回看图谱、实时区四块能力都比现行 Vue 版强，移植时需同步补 `/api/market/*` 的调用与图谱渲染器。
3. **行情源当前不可用**：东财 `push2` 在本会话后段开始拒绝本机客户端（换镜像域名、换 TLS 指纹、curl 与 httpx 同样被拒），故 `quote` 返回「未接入」；公告／新闻／语料内三源可用。
4. **演示只用一条真实问答**（平安银行×伊利股份，8 证据／17 路径）；其余历史行标「未收录回看」，点开是空态，不补内容。
5. 单文件 193KB，超出「单文件约 1000 行」的常规约束（为满足自包含要求而保持不拆）。
