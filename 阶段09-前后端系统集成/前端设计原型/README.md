## 二、界面上的字全部来自真实记录

底本是 `ashare_qa` 六表里的**一次真实问答**（导出脚本 `_工作底稿\取真实问答样例.py`，内容卡 `_工作底稿\出内容卡.py`）：

```
【问题】平安银行与伊利股份共同参与的事件是什么？
【证据】8 条：公告来源 6（巨潮资讯网；2026-07-03／2026-08-01／2026-08-22／2026-08-25）+ 新闻来源 2
        含 doc_id／chunk_id（如 1337／1337001）
【图谱】17 条路径，深度 1～2；样例 000001 -HAS_EXECUTIVE(confidence=0.9,
        source_doc_id=1337, source_chunk_id=1337000)-> PER-0010；事件三元组 EVT-0236／0260／0823／0827
【判定区间】不适用（本题不含相对时间表述）
【口径】deepseek-flash ／ Prompt v1.0 ／ 数据集 v2.1 ／ 数据截止 2026-09-25T23:59:59+08:00
```

**空值也如实呈现**：本次未命中的来源类别显式写「本次回答未命中该来源类别」；记录里没有的字段留白并标「未给出」，**不补写**。

1. **未做真实浏览器渲染验证**：本机无浏览器自动化，OpenDesign 的截图导出只在桌面运行时可用

   我另做 79 项文件级核验；**界面外观本身没有经过人眼或渲染确认——请作者在浏览器里看**
