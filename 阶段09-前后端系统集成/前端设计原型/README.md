## 一、作者第三轮两条意见（2026-10-01）与实现

| 作者原话 | 实现 |
| --- | --- |
| 「知识图谱**有遮挡**」 | ① `layout()` 改为**确定性分层环形**：中心实体在圆心、1 跳内环、2 跳外环，同环按 `2πk/n` 等角，**弧距不足时迭代放大该环半径**，节点半径按连接数分级但**钳位 14–30px**；② 标签按**优先级**取舍（选中＞邻居＞Top-K）＋**矩形两两相交检测**（相交则隐藏优先级低者并计数）＋14 字符截断＋`paint-order` 描边光晕；③ **图例从画布浮层改为画布上方流式横条**，**属性面板移入独立右栅格列**（旧浮层 `.glegendBox`／`.gzctl`／`.gzoomv` 的 CSS 与 DOM 均已删除）；④ 边默认不显示文字、悬停/选中才出「中文关系名＋置信度」，并行边贝塞尔分叉、从节点边缘起止；⑤ 初始 fit-to-view ＋ 适应窗口／滚轮锚点缩放／拖节点（边实时跟随）／拖空白平移；⑥ 每帧跑**几何自检**并在画布下方状态行如实打印实测值，例如 `遮挡自检：节点重叠 0 · 标签重叠 0 · 可见标签 4/7 · 已隐藏 3 个标签（悬停查看）· 缩放 ×1.672` |
| 「每个实体展示的**证据不够充足**」 | 进屏**默认选中实体**（不再要求先点一下），实体证据区四块：① **计数概览**（真实实测：邻居／关系／涉及文档／不同文本块）② **关系证据表**（逐行给 `中文关系名`／`对端实体`／`ROLE`／`CONFIDENCE`／`SOURCE_DOC_ID`／`SOURCE_CHUNK_ID`，每行两个动作「查看原文 ↗」（`document.url`）与「查看上下文」（`GET /api/documents/{doc_id}/chunks/{chunk_id}`））③ **文档聚合**（按文档去重：标题·来源站·发布日期·支撑关系数·外链）④ **事件实体额外四项**（参与者含 role／发布机构／相关政策／多来源证据按发布时间升序、最早一份标「主要来源」）。**缺字段如实标注**：某行文档未给 url 就写「记录未给出 url」并禁用外链按钮，不编造 |

**后端配套（真实接口，不是原型里的假数据）**：本轮新增 `GET /api/graph/entities/{node_id}/evidence?depth=1|2&page=&page_size=`，一次返回该实体的完整证据（`counts`／`documents[]`／`relations_without_evidence[]`），**只发 2 条批量 SQL**、暖态 60–70 ms；并给既有 `neighbors`／`paths` 加可选开关 `with_evidence=1`（默认关时响应逐字节不变）。详见 `代码\后端\README.md` 与《25》修订记录 v1.6。

## 二、决策者独立核验

- **机检**：`_工作底稿\决策者核验\核验_前端设计原型v5.py` —— **56 项全部通过、退出码 0**（含按 CSS 定位判定「图例/缩放浮层确已不在画布上」、DOM 级确认默认选中实体与遮挡自检状态行、以及 v3／v4 全部既有纪律不得回退）。
- **目视**：本机装有 Chrome／Edge，改用**无头渲染 ＋ 截图 ＋ 视觉读取**对四屏逐屏核对（脚本 `_工作底稿\截图前端原型.py`）。**这是本轮方法论上的升级**——此前登记在案的「本机无浏览器自动化、界面未经目视」限制就此解除。
  - 踩坑已写进脚本注释：原型把当前屏存 `localStorage` 会覆盖切屏；`.reveal` 初始 `opacity:0` 且会被自身逻辑反复撤销，**必须注入 CSS `!important` 强制显形**，否则截图发灰会被误判成「设计对比度不足」（我差点误判，已排查纠正）。
  - 目视发现的三个残留问题（画布留白、对比度、背景曲线横穿）已作为 v5.1 的定点细化内容交给生成方，并再次目视确认。

## 三、已知限制（如实登记）

1. **原型不是 `代码\前端\` 的 Vue 实现**：设计→组件移植仍属延后项；且原型能力已明显强于现行 Vue 版（图谱渲染器、实体证据区、实时区、回看图谱），移植时需同步补 `/api/market/*` 与 `/api/graph/entities/{id}/evidence` 的调用。
2. **边标签仍有轻微贴边**：状态行的遮挡自检统计的是**节点圆与节点标签矩形**，悬停时出现的**边标签**（如置信度 `0.9`）未纳入该检测，目视可见个别边标签贴到节点边缘。属可接受残留，已登记。
3. **行情源当前不可用**：东财 `push2` 拒绝本机客户端，`/api/market/quote` 如实返回「未接入」；公告／新闻／语料内三源可用。
4. **原型演示只用一条真实问答**（平安银行×伊利股份）＋三个真实实体（601633／000001／EVT-0001）的证据，其余历史行标「未收录回看」。
5. 单文件 265KB，超出「单文件约 1000 行」的常规约束（为满足自包含要求而保持不拆）。
