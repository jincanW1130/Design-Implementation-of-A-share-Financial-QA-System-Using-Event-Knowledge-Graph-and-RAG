## 一、需求（作者 2026-09-30 提出）

> 用 open design 设计一个有**红元素、股票元素、牛元素、科技赛博元素**的前端。

落到设计任务上的四条硬性要求：

1. **红元素**——以中国 A 股「红涨」为色彩逻辑，正红／朱红作主强调色，近黑深色底承托；
2. **股票元素**——K 线（红阳绿阴）、成交量柱、行情跑马灯、盘口与指标数字（等宽字体、红涨绿跌）；
3. **牛元素**——几何化牛头／牛角（**内联 SVG 自绘**）、牛字印章，用于徽标、加载态与空状态；
4. **科技赛博元素**——霓虹辉光、扫描线与 CRT 微噪、透视网格、HUD 切角面板、故障艺术标题、等宽字体栈。

界面须覆盖本系统的四类页面：**提问台 / 答案与证据 / 事件知识图谱 / 历史记录**，且与系统口径一致
（答案固定四段「【回答】】【证据来源】【知识图谱路径】【数据截至与判定区间】」、证据四类分组、
「本次回答未使用图谱扩展」固定字样、数据截至 2026-09-25、运行探针含 `deepseek-flash`）。

## 二、核验结论（决策者独立复核，**不采信生成方自报**）

复核脚本：`阶段09-前后端系统集成\_工作底稿\决策者核验\核验_前端设计原型.py`（27 项，**全部通过、退出码 0**）：

- **基本形态**：完整 HTML 文档；**零外部依赖**（无 http(s) 外链、无 CDN 与外部字体、无外部图片）；内联 SVG 14 处；
- **四类元素**：红系三色 hex 落地（`#E63946`／`#FF2D2D`／`#C8102E`）＋ 绿色仅 `#22C55E`；
  股票类命中 9 项（candle／跑马灯／tape／成交量／盘口／600519／均线／换手率／市盈率）；
  牛元素 `bull` 出现 25 次；赛博类命中 8 项（glitch／扫描线／网格／grid／霓虹／hud／噪／noise）；等宽字体栈；
- **系统口径一致**：四个固定段头**逐字**存在；「本次回答未使用图谱扩展」逐字；`2026-09-25`；证据四类分组齐备；含 `deepseek-flash`；历史回看「不重新渲染」提示；

## 三、已知限制（如实登记）

1. **未做真实浏览器渲染验证**：本机无 Playwright／Selenium，OpenDesign 的截图导出又只在桌面运行时可用
   （生成方实测返回 `screenshot export is only available in the desktop runtime`）。因此
   「1440px 下无横向滚动」是**静态推断**（栅格与溢出规则层面）而非目视结论，**请作者在桌面浏览器打开确认一次**。
2. **原型是单文件 HTML，不是 `代码\前端\` 的 Vue 实现**：把它落到工程里需要一次「设计 → 组件」的移植
   （拆分 `views\`／`components\`、把色板与字体栈落进 `src\assets\` 一套 CSS 变量、把内联 SVG 提成组件）。
   **本次未做移植**，属延后项。
3. **文案与数字是演示样例**：原型里的行情、证据、图谱节点均为贴近本课题场景的**构造样例**，
   不是系统实测输出——不得作为任何读数引用。
4. 单文件 1971 行，超出「单文件约 1000 行」的常规约束（为满足「自包含单文件」的硬要求而保持不拆）。
