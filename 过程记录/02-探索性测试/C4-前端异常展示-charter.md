# C4 · 前端异常展示 — 探索性测试 charter

> 状态：**待执行（需浏览器环境；依赖 S8 Playwright 资产先行落地）**

## Charter

- **探索**：前端（Vue 3 + Vite dev server）在**后端各类故障**下的展示与交互；
- **使用**：Playwright（S8 落地后复用其浏览器环境）＋ 手工走查；后端故障用「停依赖」
  与「改配置指向不可达端口」两种方式制造；
- **关注**：
  1. 后端完全不可达时，四个视图（提问台／答案与证据／知识图谱／历史记录）是否给出
     可理解的错误提示（而非白屏／控制台裸错误／无限 loading）；
  2. 后端返回 4xx/5xx 错误码（1002／1003／2001／3001／3002）时，错误文案是否面向用户
     （不泄漏内部路径、不出现原始 JSON）；
  3. 请求进行中（问答 10~30s）离开页面／重复提交的行为（防重复提交已有，观察离开场景）；
  4. 图谱后端不可用（3001）时图谱视图的降级文案与「图谱未接入」状态是否如实；
  5. 回看抽屉（M13 修复后）的键盘行为：Tab 循环是否困于抽屉、Esc 关闭、焦点还原是否生效；
  6. 无障碍顺带观察：`role="tabpanel"` 的 aria-labelledby（M13 已补 id）在浏览器实测中
     是否被读屏语义正确关联；
- **时限**：45 分钟（含制造故障的准备）。

## 执行前置

1. S8 的 Playwright 环境就绪（`tests_e2e/` 可启动浏览器）；
2. 后端＋前端 dev server 运行中；
3. 准备一台可切换的故障环境：停 MySQL／停 Neo4j／停后端 三档。
