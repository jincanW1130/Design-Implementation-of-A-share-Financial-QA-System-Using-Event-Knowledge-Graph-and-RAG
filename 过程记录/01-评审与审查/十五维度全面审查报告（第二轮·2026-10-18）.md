## 一、缺陷清单（本轮新发现）

### F3（已修）：超大 `page` 参数 → HTTP 500

- **现象**：`GET /api/history?page=999999999999999999999` → 500＋9999。
- **根因**：`(page-1)*page_size` 溢出到 10^21 量级，拼进 `LIMIT` 生成非法 SQL
  （`near '19999999999999999999960'`）→ `pymysql.ProgrammingError` 未捕获。
- **修复**：`api/history.py` 新增 `PAGE_MAX = 100000`，超限按 **1002** 拒绝。
- **测试**：`test_g2_history_page_overflow_is_1002`（3 种非法 page）；**293 passed**。

### F4（已修）：并发提问 → HTTP 500（资源耗尽）

- **现象**：3 条 `POST /api/qa/ask` 并发 → **三条全 500**。
- **根因**：每条请求都 spawn `run_answer.py` 子进程，各自 `AutoModel.from_pretrained` 加载本地
  BGE 模型；第三个进程触发 `OSError: 页面文件太小（os error 1455）`，链路退出 1 → 后端按
  `retrieval_chain_failed` 判 3003/500。
- **修复**：`qa_service._ASK_LOCK` 串行化重资源链路（单机演示形态），其余请求排队；
  每条链路仍保留 300s 超时。
- **复验**：3 条不同问题并发 → **3×200**，`answer_id` 互不相同（32／34／33），串行排队 38.4 s。

### F5（已修）：缺少基础安全响应头

- **现象**：响应无 `X-Content-Type-Options`／`X-Frame-Options`／`Referrer-Policy`。
- **修复**：`main.py` 增加 HTTP 中间件补三个零风险头。CSP 不在后端设（后端只输出 JSON，
  应由静态服务器统一设）。

### F6（已修）：跨引擎走查夹具写死 `answer/40`

- **现象**：本轮跨引擎走查突然出现 **22 个 major**，答案页 404、控制台 3 条 404。
- **根因**：脚本把答案页写死为 `/answer/40`——40 号是当时临时跑出来的问答，数据库按交付基线
  清回 30 条后该页已不存在。**是夹具过期，不是产品回归。**
- **修复**：改为启动时自 `/api/history?session_id=S-001` 解析真实 `answer_id`（取不到回落 16）。
- **复验**：**pass 108／info 21／major 0／error 0**（夹具打印 `/answer/30`）。

## 三、维度 4：响应契约（5/5）

- 11 个 GET 成功响应均含 `data` 与 `meta`；`/api/health` 按《24》3.5 裸对象返回（设计如此）。
- 错误响应键集 ⊆ `{code, message}`，无 `detail` 泄漏。
- 13 个错误码的 `errors.py` 状态映射自洽；抽样（2001）实际 HTTP 与映射表一致（404）。
- 分页、类型、缺失参数三类非法输入全部落在 1002／1003／2001。

  路径穿越、300 字长串、控制字符、ANSI 转义）× 3 端点（history／graph／answers）→ **0 次 5xx**。
- 类型混淆 7 组：`page=abc`→1002、`page_size=-5`→1002、`page_size=100000`→1002、
  `dep`=errors、`depth=-1`→1002、`hops=99`→200（被夹取）、**`page` 溢出→500（已修）**。

## 十二、误报与口径修正（记录备查）

1. **行业分布为空**：`documents.jsonl` 并无 `industry` 字段（行业在 `dataset.json` 汇总），探针假设错。
2. **时间分布「集中在一年」**：数据集本就限定 4 个月窗口，属设计而非缺陷。
3. **正文首 200 字相同 → 判为重复**：实为公告／法律意见书的标准开头，标题与全文均不同。
4. **3 条并发提问返回同一 `answer_id`**：是 `_next_ids` 的**幂等复用**（同会话＋同问题），非缺陷。
5. **`mask-image` 命中 `sk-`**、**`Content-Type` 大小写**：探针自身缺陷，已修正。
