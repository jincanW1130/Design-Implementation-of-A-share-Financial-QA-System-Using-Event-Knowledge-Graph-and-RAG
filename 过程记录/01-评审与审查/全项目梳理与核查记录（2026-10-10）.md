## 二、缺陷类（**已修**）：重组把「文件相对链接」当成「仓库根相对路径」改写

### 2.1 事实与成因

2026-10-09 的顶层目录重组用一个**仓库根相对**的映射表（`图表` → `交付物/09-图表` 等）去替换全库路径字符串。这个做法对**引用路径**是对的，但对 **Markdown 文件相对链接**是错的——链接的解析基准是**文件自身所在目录**，而文件本身也被移到了新位置。

实测重组前的原句（`git show 0f2b2903^`）：

```
![图 4-1　六层架构与部署形态](../图表/第4阶段图/图4-1-六层架构与部署形态.png)
```

重组后变成 `](../交付物/09-图表/…)`；而该文件现在位于 `交付物/01-论文/_分章源文件/`，于是解析结果是
`交付物/01-论文/_分章源文件/交付物/09-图表/…`——**磁盘上不存在**。

### 2.2 影响面（实测，共 **34 处**）

| 文件 | 坏链数 |
| --- | --- |
| `交付物/01-论文/29-第11阶段产出文档（毕业论文）.md`（生成物） | 9 |
| `交付物/01-论文/_分章源文件/04-第四章-系统设计.md` | 8 |
| `交付物/07-设计与需求/总体设计/10-系统总体设计（第四阶段）.md`（生成物） | 8 |
| `交付物/07-设计与需求/总体设计/_分节源文件/` 下的 5 个文件（4.1／4.3／4.4／4.5／4.6） | 1／2／2／1／2 |
| `交付物/01-论文/_分章源文件/03-第三章-系统需求分析.md` | 1 |
| **合计** | **34** |

后果：**Markdown 预览器里论文与设计文档的 9 ＋ 8 张图全部裂开**。而 `工具/验收第11阶段.py` 的 E3 当时只检查**图注里反引号包起来的**路径存在性、**完全不看 `![]()` 链接**，所以它放过了一个"正文里 9 张图全裂"的产物。

### 2.3 各文件位置的**正确相对前缀**（实测 `Test-Path`，四档各不相同）

| 文件位置 | 前缀 |
| --- | --- |
| `交付物/01-论文/29-….md` | `../09-图表/` |
| `交付物/01-论文/_分章源文件/….md` | `../../09-图表/` |
| `交付物/07-设计与需求/总体设计/10-….md` | `../../09-图表/` |
| `交付物/07-设计与需求/总体设计/_分节源文件/….md` | `../../../09-图表/` |

### 2.4 修法（三层，缺一不可）

1. **源文件**改正前缀（上表），生成物一律**重跑拼装脚本**产生、不手改。
2. **两个拼装脚本**（`工具/拼装第十一阶段论文.py`、`工具/拼装第四阶段文档.py`）新增**链接重定位**：因源文件与产出文件的层级不同，逐字拼接必然错位，故由脚本把「相对源文件」的链接改写为「相对产出文件」，并在**写盘之前自检**——产出里每一条仓库内相对链接都必须解析得到，否则非零退出、不写盘。
3. **门禁加严**：`工具/验收第11阶段.py` 的 **E3** 由「9 条图注 PNG 路径存在」加严为「图注路径 **＋ 正文 `![]()` 链接**全部存在」；**不新增行**（A～G 与 23 行结构不变），并追加一条定向篡改反例。

### 2.5 修复后的独立复算（决策者本人跑的）

判据：`.md` 里目标非 `http(s)://`／`#`／`mailto:`／`data:`，且形如 `./…`、`../…` 或含 `/` 的链接算「仓库内相对链接」；解析顺序＝先按**文件所在目录**、再按**仓库根**。

```
全仓库 .md 相对链接 = 48
解析不到           = 0
```

## 六、`.gitattributes` 的行尾覆盖缺口（**已修**）

原规则只覆盖 `.md/.py/.html/.csv/.json/.cypher/.jsonl/.txt/.tsv`；`.ps1／.js／.svg／.log／.sha256／.xml／.sh／.vue／.css／.ini／Dockerfile` 等一律落在 `* text=auto` 上——**入库时**归一为 LF，但**检出时**按 `core.eol=native` 变 CRLF。这与本项目「文本一律 LF 存储」的确定性纪律冲突，且：

- `.sha256` 是抽取与图谱产物的**完整性清单**，行尾变化破坏 `sha256sum` 类校验；

- 换机／重新克隆会得到一份字节与工作区不同的副本。

**已补**：为上述文本类型显式写死 `text eol=lf`；为 `.pptx／.xlsx／.index／.jpg／.jpeg／.gif` 显式 `-text`；`.dockerignore` 与 **`Dockerfile`（不限深度——本仓库的 Dockerfile 在 `交付物/10-部署/`，用 `/Dockerfile` 匹配不到，已实测）**一并纳入。

1. **唯一交付物单点定义**：`交付物/01-论文/提交件/王锦灿_20234225193_基于事件知识图谱与RAG的A股财经信息智能问答系统设计与实现.docx`（学校文件名体例）。旧落点《30》的删除已写进脚本（`STALE_OUT_REL`），实盘确认**《30》已不存在、只剩一份 Word**。
