## 二、渲染口径（可复现）

1. **图的来源**：`阶段04-系统总体设计\_分节源文件\` 里 `4.1`～`4.6` 六个源文件的 8 个 ```mermaid 代码块，按代码块出现顺序对应图 4-1～图 4-8（4.7 无图）。
2. **两条渲染通道**：`npx -y @mermaid-js/mermaid-cli@11`（mmdc）在本机可用、探测跑通（退出码 0）；但 mmdc 不便于统一字体、内边距与图题，最终成品取**本机 Python playwright 1.61.0 ＋ msedge 通道**（Edge 151.0.4129.72，无头）＋ 本地 mermaid 11.12.0 bundle 的通道，渲染过程**不联网、不起本地服务**。
3. **尺寸口径**：mermaid 图按自身 viewBox 的自然尺寸渲染、不拉伸；画布宽度取"自然宽 ＋ 留白"与 2400 css px 中的较大者，再以统一 deviceScaleFactor 3.5 栅格化，因此 8 张图在 Word 里缩到同一栏宽后**字号互相一致**。
4. **确认方式**：8 张图逐张目视核对——中文无方框／缺字、连线与箭头不截断、图题在图上、节点与文字未被裁切。
