> "两张 HTML 图都可以在浏览器里直接看；**转 Word 时各自导出为 PNG 用作插图**"。

## 二、渲染口径（可复现）

1. **无头渲染**：`playwright.chromium.launch(executable_path=r"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe", headless=True)`——与第 4 阶段那 8 张图（`交付物/09-图表\第4阶段图\`）同一通道。
2. **不联网**：以 `file:///` 打开本地 HTML，并以 `page.route("**/*")` 中止所有非 `file://`／`data:` 请求；实测被中止的请求数为 **0**，即两张 HTML **完全自包含**（无 CDN 脚本／字体／图片引用），因此不存在"缺样式"的加载失败。
3. **deviceScaleFactor ＝ 3**（≥ 任务要求的 2），视口宽 **1240 css px**——大于两张 HTML 的 `.page`／`.wrap` 上限 1180 px，既不会触发各自的 `max-width:760px` 窄屏适配，也不会横向裁切。
4. **整页截图**：`page.screenshot(full_page=True)`。整页判定不靠目测——落盘像素高 ÷ 3 与页面 `document.scrollHeight` 逐张比对：六层架构图 5298 ÷ 3 ＝ **1766** vs `scrollHeight` 1766；路线图 4434 ÷ 3 ＝ **1478** vs 1478，两张均**逐像素相等**，确认为整页。
5. **横向不裁切**：逐元素取 `getBoundingClientRect().right` 的最右边界，两张均为 **1240.0 ≤ 视口宽 1240**，即无元素越过视口右缘。
6. **白底**：两张 HTML 的 `body` 原为浅色渐变／浅灰底（`#f5f8fc→#e9eff7` 与 `#eef2f7`）；渲染时注入 `html, body { background:#ffffff !important; }` 覆盖为纯白（与两张 HTML 自带 `@media print` 里的白底口径一致），`getComputedStyle(body).backgroundColor` 实测为 `rgb(255, 255, 255)`。
7. **中文不缺字**：字体族取 HTML 自带的 `"Microsoft YaHei"`（本机已装），渲染后逐张目视核对，中文全部正常、**无方框／无缺字**。
8. **四边留白裁切**：截图为纯白底，故用 Pillow 以"与纯白的差分外接框 ＋ 四周各留 24 px"裁掉多余白边（不缩放、不拉伸、不改变内容），尺寸由 3720×5298 → **3588×5169**、3720×4434 → **3588×4434**。
9. **粗图在 Word 里的观感**：两张图宽度同为 3588 px，缩到同一栏宽后**字号互相一致**（与 `交付物/09-图表\第4阶段图\` 的做法一致）。
