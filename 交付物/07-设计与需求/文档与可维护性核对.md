### 5.2 函数/类 docstring 覆盖率

对上述 11 个模块做 AST 统计：

| 指标 | 值 |
| --- | --- |
| def/class 总数 | 335 |
| 带 docstring | 260 |
| 覆盖率 | **77.6%** |

未覆盖的主要是小型私有辅助函数（如 `_s`、`_iso`、局部格式化函数）与少数测试用 helper；
公共函数、关键算法入口、易误用函数均有说明。

### 5.3 注释质量要求（建议写入维护规范）

1. **口径注释**：凡是会影响实验读数或接口语义的常量（K/N/预算/g、阈值、超时、限流），
   必须注明来源与冻结依据；
2. **反例注释**：修复过的缺陷要写明「原实现为什么错、实测症状、修复后读数」，便于回归；
3. **不改口径的重构**：必须在注释或提交信息中说明「语义等价」并提供测试证据；
4. **禁止注释掉的代码**：用版本控制保留历史，不在源码里留大段死代码；
5. **中文注释**：项目内部统一中文；公共接口名保持英文。

2. **引用而不复制**：汇总文档引用产物路径，不手工抄写易漂移的读数；
3. **口径限定必写**：模型评分非人工、参照集非金标准、预实验≠正式集；
4. **不新建带编号交付文档**：新补充文档用不带编号的名字，放在对应目录；
5. **论文/答辩目录只读**：任何优化轮次均不得修改。
