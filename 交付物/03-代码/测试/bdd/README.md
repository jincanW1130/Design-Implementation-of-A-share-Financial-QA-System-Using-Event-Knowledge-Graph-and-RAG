# bdd —— BDD 试点（审查报告「BDD 规格」维度的试点落点）

> 2026-10-11 新建。报告结论「BDD 零资产（低频可选，试点即可）」——本目录即试点：
> **一个 feature ＋ 一个零依赖轻量执行器**，不引入 pytest-bdd、不进主套件
> （`运行测试.ps1` 不收集 bdd/，其文件不以 `test_` 开头）。

## 运行

```powershell
python 交付物/03-代码\测试\bdd\runner.py
```

退出码 0＝`错误码契约.feature` 的全部场景通过（TestClient 进程内执行，离线）。

## 文件

| 文件 | 说明 |
|---|---|
| `错误码契约.feature` | Gherkin 中文场景 5 个：1001（空输入）／1002（非法 JSON）／1003（缺必填）／2001（资源不存在）／2002（空结果不是错误） |
| `runner.py` | 极简 Gherkin 解析 ＋ When/Then 映射表（`STEPS` 逻辑内联）——场景扩写时先加映射再加场景 |

## 扩写纪律

试点**不是**全量 BDD 化的承诺：场景扩写按「一条场景对应一个既有契约断言」推进
（映射到 test_g 已钉住的错误码行为），**不得**为 BDD 单独新造行为断言；`When/Then`
未映射的行会让执行器如实报 `??`，不留静默跳过。
