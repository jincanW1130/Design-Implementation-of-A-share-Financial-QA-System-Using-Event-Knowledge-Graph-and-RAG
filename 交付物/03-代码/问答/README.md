# 交付物/03-代码\问答 —— 第 8 阶段（智能问答系统）答案生成层

本目录是第 8 阶段的**答案生成层**：把第 7 阶段（RAG 检索系统）冻结的检索结果，经
Prompt 组装 → 答案生成模型 → 带引用的四段答案，并落成可复现、可机检、可回看的产出。

唯一规格是 `交付物/05-系统实现/智能问答系统\21-第8阶段任务书（智能问答系统）.md`（v1.5）。本目录
**只读**第 5／6／7 阶段的产出与代码，不改动其中任何一个字节（《21》第五节 硬约束 1）。

## 二、约定（口径与纪律）

1. **四项定值只从 `交付物/03-代码\检索\config.py` 导入**：K=10、N=20、Context Token Budget=3600、g=2。
   命令行 `--k／--n／--budget` 只接受**冻结值**，传入非冻结值**报警并拒绝**（硬约束 1／21）。
2. **答案侧冻结值**：`model_name=deepseek-flash`、`temperature=0`、`max_tokens=16384`、
   `prompt_version=v1.0`、`timeout_seconds=300`；端点 `https://api.deepseek.com/v1`。
   `max_tokens=16384` 的依据：该端点返回**推理过程**（与正文**共享**同一预算），
   2048 时正文为空、4096 时截断，16384 才稳定以 `finish_reason=stop` 收尾。
3. **空正文重试规则**：正文为空串时用**完全相同**的配置重试一次；两次都记入 `attempts`；
   两次都空 → 该题失败、非零退出，**不写空答案**。
4. **日期来源可核**：答案中每个年月日必须来自——证据正文／标题／发布时间、图谱载荷、
   `data_cutoff_time` 的日期部分、或窗口规则推出的判定区间端点（「最新」＝基准日、
   「最近」＝前 30 天、「近期」＝前 90 天）。三条都不满足才算**越界**（`date_unverifiable`）。
   证据里明写的、晚于截止时间的日期单列 `dates_beyond_cutoff`，**只统计、不计入失败**。
5. **禁词表是固定常量**：只收**推荐／评级／价格判断／买卖动作**类**成词短语**；不收在冻结
   证据正文里本就字面出现的**事实性叙述词**（`预计`／`减持`／`预测`／`增持`／`上涨`／
   `风险提示`）——收进去会把「正确引用公告原文」判成违规。词表是**有限枚举**，不是语义判别器。
6. **术语纪律**：向量库一律写「向量索引」；不声称部署了图数据库服务（图谱以**载荷**形式
   随证据集合进入 Prompt，不连任何服务）。
7. **密钥纪律**：读环境变量 `LLM_API_KEY`，否则读 `交付物/03-代码\抽取与图谱\config.local.json`
   的 `api_key` 字段；**不写死、不回显**，只允许打印「可用／不可用」。
8. **确定性**：装配层（Prompt 文本）**逐字节可复现**；模型侧不做承诺，按**实测重复率**
   如实报告（不作为通过标准）。
9. **时间字段由 `--now` 注入**（格式决策 5）：`ask_time`／`create_time` 不读系统时间。

## 三、四段答案的形成方式（硬约束 7／8）

一段答案固定四段，**只有第一段由模型生成**，其余三段由**代码确定性拼装**：

| 段 | 来源 | 内容 |
| --- | --- | --- |
| 【回答】 | **模型** | 仅模型正文；引用记号固定 `[证据n]`，n ∈ 1..m（m ＝ 本题证据条数） |
| 【证据来源】 | 代码 | 逐条渲染本题证据集合的元数据（序号／来源类型／文档／发布时间／标题），正文由 `assemble.py` 原样带入 |
| 【知识图谱路径】 | 代码 | `graph_payload.graph_used` 为真时渲染路径与事件三元组；为假时固定写 `本次回答未使用图谱扩展` |
| 【数据截至与判定区间】 | 代码 | 数据版本、数据截止时间、相对时间判定区间（无约束时显式写「无判定区间」） |

因此：**图谱路径与判定区间不是模型写的**——模型正文里若出现系统段的标记或小标题，
按**泄漏**判失败（`body_graph_marker_leak`／`body_section_header_leak`）。

`history.py` 落记录时，`graph_path` 取 `graph_payload.graph_path` 的**原样 JSON 文本**，
**不加工、不重排、不渲染**（硬约束 7）。

## 四、门禁清单（T6 机检；全部通过 `passed` 才为真）

作用域：**引用编号／图谱泄漏／小标题泄漏**只看模型正文；**日期／禁词**看答案全文
（含代码拼装的三段，构造上即落在允许来源内，不产生假阳性）。

| 门禁键 | 判据 | 通过条件 |
| --- | --- | --- |
| `citation_out_of_range` | `[证据n]` 的 n ∉ 1..m | 越界 0 次 |
| `citation_missing` | 至少 1 个引用记号 | 有引用 |
| `date_unverifiable` | 日期三条来源都不满足 | 0 次 |
| `graph_section` | 图谱段与 `graph_used` 一致 | 一致 |
| `body_graph_marker_leak` | 模型正文含「未使用图谱扩展」标记 | 无 |
| `body_section_header_leak` | 模型正文含系统段小标题 | 无 |
| `forbidden_terms` | 禁词命中 | 0 次 |
| `evidence_backlink` | 证据集合可回链到语料 | 通过 |
| `empty_answer` | 非空正文 | 非空 |
| `time_note` | 时间段含判定区间与截止时间 | 合规 |
| `open_ended_marker` | 开放式题含固定标注 | **不适用即通过**（题集无开放式题 → `not_applicable`） |

失败的门禁**不进入正式输出**：脚本非零退出并打印失败详情；`--all`／`--run-manifest`
还会把失败题的**完整模型正文**写进 `交付物/05-系统实现/智能问答系统/_工作底稿/门禁失败明细.json`
供事后核对（判定仍按**字面**命中，不因上下文放宽）。

## 五、常用命令

```bat
python 交付物/03-代码\问答\model_selection.py --recheck        :: 选型复检（0 调用；重算机检＋逐行 prompt_sha256，幂等）
python 交付物/03-代码\问答\answer.py --selftest                :: T5／T6 自检（PE-01 端到端 ＋ dry-run 0 调用）
python 交付物/03-代码\问答\history.py --selftest               :: T7 自检（会话隔离／联合唯一／回看不重渲染）
python 交付物/03-代码\问答\run_answer.py --qid PE-01           :: 单题端到端（写产出）
python 交付物/03-代码\问答\run_answer.py --all                 :: 30 题录制（30 次调用）
python 交付物/03-代码\问答\run_answer.py --selftest            :: ① 单题 ② dry-run 0 调用 ③ 装配 SHA-256 ④ 会话隔离
python 交付物/03-代码\问答\run_answer.py --run-manifest        :: 两次运行 ＋ 装配一致性（约 60 次调用）
python 工具\跨文档核验.py                            :: 跨文档一致性核验
```

零调用镜像重跑（PowerShell，跑完记得清掉环境变量）：

```powershell
$env:STAGE8_FORBID_MODEL_CALLS=1
python 交付物/03-代码\问答\run_answer.py --dry-run
Remove-Item Env:\STAGE8_FORBID_MODEL_CALLS
```

`--question` / `--group A|B|D|E`：**不新增检索实现**——以**子进程**调用第 7 阶段既有链路
（`交付物/03-代码\检索\run_query.py`，只读）取该题的 trace 行，再走同一条生成链路；桥接产出落在
`交付物/05-系统实现/智能问答系统/_工作底稿/桥接/`。若该路径在本环境不可行，**如实报错并退出**，
不静默降级（《21》第五节 硬约束 1）。
