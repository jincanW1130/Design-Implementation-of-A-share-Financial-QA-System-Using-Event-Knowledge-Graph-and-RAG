# 增强层（工程增强，不参与论文实验口径）

本目录收纳**本项目优化过程中新增**的工程增强模块。它与上游只读目录
`交付物/03-代码/检索/`、`问答/`、`数据准备/` 严格分开：

* 上游目录保持**只读＋文件级指纹**（`交付物/05-系统实现/前后端系统集成/_工作底稿/决策者核验/输入指纹.py`），
  不再混入本优化新增的文件；
* 本目录的模块**不进入 A～E 实验组**、不改变任何既有实验读数、不重跑论文实验；
* 线上的关键词召回（`GET /api/search/keywords` 与空结果附带的 `related_chunks`）属于
  **工程增强**，只作补充提示，**不是证据链的一部分**。

## 文件

| 文件 | 用途 | 线上接入 |
| --- | --- | --- |
| `lexical_search.py` | 纯标准库 BM25／字符 1～3-gram 词汇检索与 RRF 融合（原 `检索/lexical_search.py`） | 由后端 `services/hybrid_search.py` 只读复用，构建进程内索引 |
| `reranker.py` | 可插拔重排序包装器（默认 `None` 不启用，只改呈现顺序、不改证据集合；原 `检索/reranker.py`） | 未接入默认链路 |
| `parse_text.py` | `.txt`／`.md` 最小解析入口（原 `数据准备/parse_text.py`） | 离线工具，不接入线上 |
| `config.py` | 兼容层：按文件路径转发 `数据准备/config.py` 的唯一参数来源（类别枚举等），避免复制字面量 | — |

## 口径

* 本目录**不是**论文实验组的一部分；论文与答辩中的 A～E 读数、检索指标与门禁判据
  均不受本目录影响；
* BM25 的离线对照读数见 `交付物/05-系统实现/RAG检索系统/混合检索与重排序方案.md`；
* 线上接入的动机、实现与实测见 `交付物/05-系统实现/性能与架构优化方案.md`
  的「关键词召回（工程增强）」一节。
