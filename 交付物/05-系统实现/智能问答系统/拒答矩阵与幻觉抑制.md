# 拒答矩阵与幻觉抑制（第 5 轮 · 任务十二.1）

> 本文档回答三个问题：**系统在什么情况下拒答**、**拒答时用户看到什么**、**凭什么保证答案不越界**。
> 所有结论均对应冻结代码的现有实现，不引入新行为；文中路径均相对 `交付物/03-代码/`。
> 核对日期：2026-10-18。相关代码：`问答/prompt.py`、`问答/rules.py`、`问答/answer.py`、
> `问答/run_answer.py`、`后端/services/qa_service.py`、`后端/errors.py`、`后端/api/qa.py`。

---

## 一、结论先行

1. **拒答分两层**：Prompt 层的「角色边界」负责**事前**约束；机检门禁（11 项）负责**事后**拦截。
   模型输出不是「直接返回给用户」，而是先写盘、再过门禁、由后端整形后才对外。
2. **「没有可引用证据」不是报错**：乱码、脚本片段、路径穿越串、与 A 股无关的问题，在检索阶段
   没有可引用证据，模型不给 `[证据n]`，门禁只报 `citation_missing`。这类结果被**改判为
   正常空结果**（HTTP 200，`empty=true`，`empty_reason=no_citable_evidence`），前端展示中性提示，
   不返回 5xx。判定函数：`qa_service._is_citation_only_failure()`。
3. **其余门禁失败仍是 3004（HTTP 502）**：越界引用、日期不可核、禁词、证据回链失败、空答案、
   时间说明缺失等，说明「本次生成不可信」，按上游一致性守卫失败处理，**不把可疑答案交给用户**。
4. **答案的四段结构中只有「回答」由模型生成**：`证据来源`、`知识图谱路径`、`数据截至与判定区间`
   由代码按检索结果与题集元数据拼装（`prompt.ANSWER_SECTIONS`，`code_assembled_sections`），
   从结构上消除「模型编造证据编号/文档标题/图谱路径」的可能。
5. **拒答不是静默失败**：错误响应体固定 `{code, message}`，请求带 `X-Request-Id`，日志可按
   `out_dir` + 请求 ID 串联；前端按错误码给出可操作提示（见第五节）。

## 二、Prompt 层约束（事前）

### 2.1 七区块结构

`prompt.PROMPT_BLOCKS`（`PROMPT_VERSION = "v1.0"`）固定为：

| 序号 | 区块键 | 标题 | 作用 |
| --- | --- | --- | --- |
| 1 | `role_boundary` | 系统角色与任务边界 | 只做 A 股财经信息问答；不得给出投资建议、评级、目标价、涨跌预测；不得超出给定证据 |
| 2 | `data_boundary` | 数据版本与时间边界 | 注入数据集版本与 `data_cutoff_time`；截止时间之后的事实不得编造 |
| 3 | `question` | 问题 | 用户原问题（已去控制字符、折叠换行） |
| 4 | `evidence` | 文本证据 | 检索到的 K 条证据，带固定编号 `[证据n]` |
| 5 | `graph` | 图谱路径与事件三元组 | 图谱扩展结果；未扩展时由代码写入固定字样 `本次回答未使用图谱扩展` |
| 6 | `time_note` | 相对时间判定说明 | 相对时间题的判定区间（lo／hi）与数据截止口径 |
| 7 | `output_format` | 输出格式要求 | 四段结构、引用只能来自给定证据编号、开放式分析须带 `模型分析（非公开事实）` 标注 |

### 2.2 输出四段与「只有回答由模型生成」

| 段落 | 生成方 | 说明 |
| --- | --- | --- |
| `【回答】` | **模型** | 唯一自由文本段；须引用 `[证据n]` |
| `【证据来源】` | 代码 | 由答案关联的 `answer_evidence` 行渲染，含标题/来源/发布时间 |
| `【知识图谱路径】` | 代码 | 由图谱查询结果渲染；无扩展时为固定字样 |
| `【数据截至与判定区间】` | 代码 | 由 `dataset_meta()` 与题集 `time_note` 渲染 |

因此，用户看到的「证据来自哪篇公告」「走了哪条图谱路径」「数据截至哪天」都不是模型措辞，
而是可回溯的结构化字段。

### 2.3 Prompt 层的硬性话术

- **角色边界**：只答 A 股财经信息；拒绝预测股价、给评级、推荐买卖；不把常识当证据。
- **引用约束**：只能使用 `[证据1]…[证据K]`，不得自造编号、不得引用编号外的材料。
- **图谱约束**：图谱段只读；不得把图谱三元组改写成新事实，不得在正文重复系统段标题。
- **时间约束**：相对时间（「去年」「最近」）按题集给出的判定区间解释；答案中的日期必须能在
  证据或判定说明中找到出处。
- **开放式分析**：若任务类型属开放式，模型分析必须以固定标注 `模型分析（非公开事实）` 开头，
  与公开事实区分。

## 三、机检门禁（事后）

### 3.1 11 项失败项

门禁入口在 `问答/answer.py` 的 gate 汇总处，失败项名称与语义如下：

| 失败项 | 触发条件 | 典型原因 | 归类 |
| --- | --- | --- | --- |
| `citation_out_of_range` | 引用了不存在的证据编号 | 模型自造 `[证据11]`（只有 10 条） | 3004 |
| `citation_missing` | 正文没有任何 `[证据n]` | 无可引用证据；或模型未按格式引用 | **单独出现时 → 2002 空结果** |
| `date_unverifiable` | 答案中的日期无法在证据/判定说明中找到出处 | 模型编造日期 | 3004 |
| `graph_section` | 图谱段与 `graph_used` 账目不一致 | 没用图谱却写了路径，或反之 | 3004 |
| `body_graph_marker_leak` | 正文出现系统固定字样 `本次回答未使用图谱扩展` | 模型复述系统段 | 3004 |
| `body_section_header_leak` | 正文出现「证据来源/知识图谱路径/数据截至与判定区间」小标题 | 模型越段输出 | 3004 |
| `forbidden_terms` | 命中固定禁词表 | 投资建议、评级、目标价、涨跌预测、交易动作 | 3004 |
| `evidence_backlink` | 答案与证据回链账目不符 | 引用编号与落库证据不匹配 | 3004 |
| `empty_answer` | 正文去空白后为空 | 模型空输出 | 3004 |
| `time_note` | 「数据截至与判定区间」段缺少截止时间/判定区间，或无时间题缺「无判定区间」说明 | 代码拼装异常或题集元数据缺失 | 3004 |
| `open_ended_marker` | 开放式题缺 `模型分析（非公开事实）` 标注 | 模型未按格式标注 | 3004 |

> 门禁是「全有或全无」：任一项失败即整条答案不可对外。唯一的例外是
> **失败集只含 `citation_missing`**——这被解释为「没有检索价值」，改判正常空结果。

### 3.2 禁词表（固定常量）

`问答/rules.py` 的 `FORBIDDEN_TERMS` 按成词短语列举，分三类：

- **投资建议/评级**：投资建议、建议买入/卖出/增持/减持/持有/投资、买入/卖出/增持/减持评级、
  强烈推荐、推荐买入/卖出、操作建议、建议关注、荐股；
- **价格/涨跌预测**：目标价、股价预测、走势预测、目标涨幅、上涨空间、下跌空间、预计上涨/下跌、
  有望上涨/下跌/突破、必涨、必跌、稳赚；
- **交易动作**：建仓、加仓、减仓、抄底、止损、止盈、看多、看空、后市。

明确的「事实性叙述词」（预测、预计、增持、减持、上涨、风险提示）**不收录**，因为它们在公告
原文中字面出现；收录会把「正确引用原文」误判为违规。该边界记录在
`FORBIDDEN_EXCLUDED_CORPUS_WORDS`，并有自检断言保证两个集合不相交。

命中判定**按字面、不因上下文放宽**；同时记录命中上下文（`forbidden_hit_contexts`）便于事后核查
是「模型在给建议」还是「模型在写免责声明」。

### 3.3 空结果判定

`_is_citation_only_failure(contract)` 的判据（`qa_service.py`）：

1. 上游结构化契约存在，且 `reason == "answer_gate_failed"`；
2. `extra.failures` 非空，且**每个题目的失败集都非空且只含 `citation_missing`**。

满足即返回 `empty=True`、`empty_reason=no_citable_evidence`，HTTP 200。契约缺失或不可解析时，
才回落到措辞匹配分类（并记 WARNING，不静默）。

## 六、幻觉抑制的边界与已知限制

**已覆盖：**

- 引用编号越界、缺失引用、日期无出处、禁词、系统段泄漏、证据回链、空答案、时间说明、开放式标注；
- 四段答案中三段由代码拼装，证据/图谱/截止时间不由模型措辞决定；
- 数据截止时间显式注入 Prompt 并在响应中回传；
- 无证据时正常空结果，不强行生成。

**未覆盖（如实记录）：**

1. **语义级幻觉**：模型在「回答」段内用正确的证据编号说出证据未直接支持的话，机检无法逐句
   核验。现有缓解是 Prompt 约束 + 人工/评测集 Faithfulness 评分（正式 120 题 C 组 1.9741/2.0）。
2. **同义改写绕过禁词**：禁词按字面命中，换成「适合买」「上行空间大」等未收录变体不会触发。
   禁词表是固定常量，扩充需重新跑门禁回归。
3. **图谱段由代码渲染**：模型无法编造路径，但若图谱本身有错（抽取/消歧误差），答案会「忠实引用
   错误图谱」。抽取评测指标见 `交付物/06-实验与评测/效果评估与前后对比.md`。
4. **引用数量与质量**：门禁只要求「至少一个合法编号」，不要求覆盖每条关键结论。
5. **空结果判定依赖上游结构化契约**：契约丢失时会回落到措辞匹配，可能把极端情况误归类（有
   WARNING 留痕）。

## 七、复现与验收

```bat
:: 1) 问答规则自检（禁词表、日期规则、引用门禁）
python 交付物\03-代码\问答\rules.py

:: 2) Prompt 结构自检
python 交付物\03-代码\问答\prompt.py

:: 3) 后端单元测试（含错误码/参数校验/问答契约）
python -m pytest 交付物\03-代码\测试 -q

:: 4) 跨文档核验（错误码表与接口文档一致性）
python 工具\跨文档核验.py --strict-citations
```

验收口径：`pytest` 全绿；`rules.py`/`prompt.py` 自检无断言失败；跨文档核验通过。
