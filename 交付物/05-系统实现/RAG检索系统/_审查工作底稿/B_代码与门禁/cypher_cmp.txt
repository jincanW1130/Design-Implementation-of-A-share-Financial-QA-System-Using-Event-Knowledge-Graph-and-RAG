228 | | --- | --- | --- | --- |
229 | | G1 | 一跳邻居 | 节点标识（`node_id`；公司可用 `stock_code`，也可按 name／short_name／aliases 匹配，**HCONF 节点只有名称、没有 stock_code**） → 直接相连的关系与对端节点 | MATCH (a {node_id:$id})-[r]-(b) RETURN a, r, b |

234 | | G6 | 时间过滤 | 事件集合 ＋ 时间闭区间（由"最新／最近／近期"或显式区间解析而来） → 通过过滤的事件集合、被剔除路径携带的 `chunk_id` 差集；**`event_time` 为空的一并剔除** | MATCH (e:Event) WHERE e.node_id IN $ids AND e.event_time IS NOT NULL AND e.event_time >= $lo AND e.event_time <= $hi RETURN e |
235 | | G7 | 路径枚举 | 起点标识、终点节点标识、最大深度（不超过 2） → 路径列表：起点、关系序列、终点；每条关系项含关系名、方向、对端节点标识，以及**除 EVIDENCED_BY 外**的三项证据属性 | MATCH p = (a {node_id:$from})-[r*1..2]-(b {node_id:$to}) RETURN p |
