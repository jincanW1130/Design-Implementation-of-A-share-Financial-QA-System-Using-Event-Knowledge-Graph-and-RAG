# 基于事件知识图谱与 RAG 的 A 股财经信息智能问答系统

> 本科毕业设计（软件工程）。把 A 股公告、财经新闻与政策文件抽成**事件知识图谱**，与**向量检索**融合，输出**带证据、可追溯**的问答。

| 项 | 取值 |
| --- | --- |
| 作者 | 王锦灿（20234225193）　指导教师：徐文莉 |
| 技术栈 | Vue 3 ＋ FastAPI ＋ MySQL 8 ＋ Neo4j ＋ FAISS ＋ 大模型 API（模型 `deepseek-flash`） |
| 数据规模 | 105 家公司／45 个行业／709 篇文档／5018 个文本块（512 维向量） |
| 知识图谱 | 3607 个节点／3614 条边；五类实体、八类事件、九条核心关系、三类时间信息 |
| 系统形态 | 单页四屏（提问／答案与证据／知识图谱／历史记录），后端 26 条业务路径／28 个业务操作 ＋ `/api/health` |
| 主结果 | 正式集 120 题（核心 108 题）完整证据召回：基线 A **0.7157** → 图谱增强 C **0.8095** |
| 明确不做 | 不预测股价、不给投资建议、不接实时行情、不做交易 |

## 跑起来

前置：MySQL 8（库名 `ashare_qa`，六表已就绪）＋ Neo4j（bolt 7687）＋ Python 3.12 ＋ Node 20+。

```powershell
# ① 后端（8000）与前端（5173）
python 交付物/03-代码/后端/run.py          # 另开一个终端
cd 交付物\03-代码\前端; npm run dev

# ② 一键启动（含四步检查）
powershell -File 交付物/10-部署/启动.ps1

# ③ 打开 http://127.0.0.1:5173
```

本机凭据只放在 `交付物/03-代码/后端/config.local.json`（已被 `.gitignore` 排除，仓库内不含任何密钥）。
