# Design-Implementation-of-A-share-Financial-QA-System-Using-Event-Knowledge-Graph-and-RAG
本课题旨在设计并实现一个基于事件知识图谱与 RAG 的 A 股财经信息智能问答系统：对财经新闻、公告与政策信息进行采集与预处理，通过实体识别、事件抽取、关系抽取与时间抽取构建事件知识图谱，并将文本向量化，形成结构化知识与非结构化文本结合的数据基础。  用户提问后，系统以向量检索与图谱检索结合的方式获取证据，通过关系路径扩展、时间约束与证据排序提高相关性，由大语言模型生成回答并提供来源，对使用了图谱扩展的回答给出知识图谱路径，实现问答可追溯；并通过普通向量 RAG 与知识图谱增强 RAG 的对比实验、不同图谱检索策略的消融实验，给出实验依据。

## 关于文献原文与数据集

本仓库**不包含**两类内容（见 `.gitignore`）：

* **22 篇文献的出版商原文 PDF 与中文译文**。《03-精选文献库（22篇）.md》给出了每篇的完整题录、池内编号与参考文献序号的映射，需要原文时按题录检索即可。
* **数据集正文（v1.0／v1.1／v2.0／v2.1）**。它们收录的是上市公司公告、监管公开信息、政策文件与正规财经新闻正文，其中新闻与公告正文是第三方文本，公开仓库不再分发。数据集本身**可复现**——`代码/数据准备/` 里的管线按同一套脚本与同一套参数重新采集即可（见下）。

## 校验

产出新文档或重建数据集后应重跑：

```powershell
python 工具\跨文档核验.py            # 全工作区一致性，14 项（A～N），退出码 0 才算通过
python 工具\验收第4阶段文档.py        # 《10》对《09》验收标准的专项检查
python 工具\验收第5阶段数据.py --with-idempotence   # 《13》与数据集对《12》第八节 的专项检查，99 项（真实重跑 103 项）
python 工具\验收第6阶段.py                  # 第 6 阶段阶段级验收：默认核验现行 v1.3（101 项）
python 工具\验收第6阶段.py --profile v21_v1_2    # 历史口径 v1.2：用 v21_v1_2 复核（101 项）
python 工具\验收第6阶段.py --profile v21    # 归档：核验 v1.1（101 项）
python 工具\验收第7阶段.py                  # 第 7 阶段阶段级验收（full 74／74）
python 工具\验收第8阶段.py                  # 第 8 阶段阶段级验收（full 39／39）
python 工具\验收第9阶段.py                  # 第 9 阶段阶段级验收（full 58／58；需先起服务）
```
