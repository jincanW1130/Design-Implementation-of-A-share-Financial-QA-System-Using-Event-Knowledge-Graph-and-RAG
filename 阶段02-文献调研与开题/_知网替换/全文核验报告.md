## 一、方法与口径

| 项 | 口径 |
| --- | --- |
| 抽取工具 | PyMuPDF 1.28.0（`fitz`）取第 1 页文本，首页题名/作者不完整时再取第 2、3 页；`pypdf` 6.19.0 交叉复核同一页文本 |
| 页数 | `fitz` 的 `page_count`（整份 PDF 的物理页数） |
| 字节数 | `os.path.getsize`（PDF 文件字节） |
| 对照物 | 《替换方案.csv》（22 数据行＝20 条替换候选＋KG-21/KG-28 两条「保留不动」）＋《_脚本\_归档池中文条目.json》（去重后 31 条中文条目，含 2 条已在库的 KG-21/KG-28） |
| 一致 | PDF 首页题名与某条候选题名一致（去空格/标点后比较，关键实词必须全中）；比较时忽略 OCR 层私用区噪声字符（PUA U+E000–F8FF，仅首页扫描件 `…_翟源昊.pdf` 命中该情形——其题名里夹着 U+E5D2/U+E5CF，去掉后与候选逐字相同） |
| 部分一致 | 题名主体一致但首页题名有增减字——须逐字列出差异（本次 0 条） |
| 不符 | 与任何候选都对不上（本次 0 条） |
| 无法判定 | 首页无文本层（扫描件/图片版）（本次 0 条） |
| 扫描件另注 | 首页为整页图像、但带 OCR 文本层的，单列说明并给出它与候选对应的证据（本次 1 条，见第五节） |
