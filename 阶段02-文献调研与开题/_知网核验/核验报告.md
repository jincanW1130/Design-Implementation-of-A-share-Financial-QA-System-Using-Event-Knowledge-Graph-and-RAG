## 一、来源性质声明

本次核验使用的是**知网空间**（`cnki.com.cn`）文章页与**知网空间检索**（`search.cnki.com.cn`），不是知网主库登录检索；两者是同一家公司的不同站点，来源性质必须区分。

- 全程**未登录**任何知网站点，**未使用、未提交、未索取任何账号或密码**；
- 脚本字段扫描模式：`账号`、`密码`、`password`、`passwd`、`pwd`、`CNKI_USER`、`CNKI_PASSWORD`；命中数见第八节。
- 工具主动访问的文章页与检索页域名是 `cnki.com.cn` 与 `search.cnki.com.cn`；浏览器加载公开检索页时，页面自身还会请求 `search.cnki.net`、`ad.cnki.net`、`mall.cnki.net` 等知网域名资源；主库域名与付费下载域名以拼接方式列入阻断表，访问清单中命中 0 条；
- 不下载全文，不点击下载链接，不访问付费下载域名；
- 检索页默认脚本请求的无响应列表接口被跳过，改由该站自身的公开列表渲染入口完成结果渲染；这不是登录、不是绕过验证，只使用同一公开检索页的可用入口。
- 本次不使用任何模型调用；全部为本地 Python 脚本、普通 HTTP 请求与无头浏览器渲染。

## 二、方法与节奏

- 先从《03》每条已有的「核验」行提取知网文件名或文章链接；本次 22 条均无现成文件名，故全部按篇名走检索。
- 采集前先对文章页样例、检索页样例与列表入口做连通性预检；任一项失败即打印错误并以退出码 3 结束，不静默跳过、不写假结果。
- 检索 URL 形如 `https://search.cnki.com.cn/Search/Result?content=<篇名>`；用 Playwright Chromium 无头浏览器渲染，读取结果区的 DOM。
- 透明说明：检索页默认脚本请求的 `/api/search/listresult` 在当前网络下长时间无响应；工具在无头浏览器内调用该站自身的 `Page0(1)`，该函数请求同站 `/search/listresult` 并把返回 HTML 渲染进 `#article_result`；若该入口未成功，则用同一入口手动注入 HTML。两条路径都不登录、不绕过验证，只使用公开检索页自身入口。
- 检索命中后，用 `requests` 直接请求 `https://cnki.com.cn/Article/CJFDTotal-<知网文件名>.htm`，不经过主库、不下载全文。
- 每条之间至少等待 2 秒；本次实际运行日志见 `运行日志.txt`。
- 证据命名：命中条目的 `<编号>.html` 是文章页原始 HTTP HTML；未命中条目的 `<编号>.html` 是检索页无头渲染后的 DOM HTML，同时把列表入口的原始返回片段保存在 `<编号>_检索响应.html`。两类都另有 `<编号>.txt` 记录抽取字段。
